# AIGxP Labs

Static GitHub Pages website for [aigxplabs.com](https://aigxplabs.com).

AIGxP Labs helps life sciences organizations identify, prioritize, and sequence AI investments that deliver the greatest value across the clinical development lifecycle.

## Site structure

- `index.html` — complete responsive homepage, including embedded styles, SVG graphics, and navigation behavior
- `CNAME` — GitHub Pages custom-domain configuration

No build step or external runtime dependencies are required.
